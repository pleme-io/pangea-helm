Auto-generated typed Helm Terraform resource functions for the Pangea IaC DSL.
All resource code is generated by `terraform-schema-importer` from the
HashiCorp Helm Terraform provider schema.

## Generation

```bash
terraform-schema-importer generate \
  --schema schema.json \
  --provider "registry.terraform.io/hashicorp/helm" \
  --provider-name helm \
  --output-dir .
```

## Resources: 1

Provides `helm_release` with full `Dry::Struct` type validation.
Module: `Pangea::Resources::Helm`, prefix: `helm_`.

## Regeneration

1. Update the provider version in a Terraform workspace
2. Run `terraform init && terraform providers schema -json > schema.json`
3. Run the generate command above
4. Run `bundle exec rspec` to validate
5. Commit the updated files

## Dependencies
